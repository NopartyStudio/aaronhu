# 并查集（Union-Find / DSU）复习笔记

---

## 一句话理解

并查集维护的是 **"谁和谁是一伙的"** 。

它只回答两个问题：

- `find(x)`：x 属于哪个集合？（返回这个集合的**代表元**）
- `merge(x, y)`：把 x 和 y 所在的两个集合合并成一个。

它**不关心**两点之间怎么走、路径长什么样，只关心**在不在同一个集合**。所以它比 BFS/DFS 判断连通快得多。

> 典型用途：动态连通性、Kruskal 最小生成树、判断无向图加边是否成环、"朋友的朋友是朋友"、"敌人的敌人是朋友"。

---

## 核心思想：用一棵树代表一个集合

每个集合选一个**代表元**（叫它"老大"），整个集合组织成一棵树，**树根就是老大**。

用一个数组 `fa[]` 存父子关系：

```
fa[x] = x 的父结点编号
```

根结点特殊：**它自己指向自己**。

```
fa[root] = root
```

于是：

- **判断 x 和 y 是否同一集合** → `find(x) == find(y)`，即"两个老大是不是同一个"。
- **合并两个集合** → 让一个老大认另一个老大当爹：`fa[rootA] = rootB`。

关键点：**数组里存的不是"集合编号"，而是一条指向父结点的边。** 这就是并查集能动态合并的原因——合并只需要改一个指针。

---

## 初始化

```cpp
int fa[N];

void init(int n) {
    for (int i = 1; i <= n; i++) {
        fa[i] = i;      // 一开始每个元素自成一个集合，自己就是自己的根
    }
}
```

> 一定要初始化。全局数组默认是 0，不写 `fa[i] = i`，`find` 会死循环或算错。

---

## 朴素写法（不优化）

### find：一路往上爬到根

```cpp
int find_root(int x) {
    while (fa[x] != x) {   // 只要不是根，就往上走
        x = fa[x];
    }
    return x;
}
```

### merge：把一个根挂到另一个根下面

```cpp
void merge(int x, int y) {
    int rx = find_root(x);
    int ry = find_root(y);
    if (rx == ry) return;  // 本来就同一集合，不用合
    fa[rx] = ry;           // 让 rx 认 ry 当爹
}
```

### 复杂度：最坏会退化成一条链

如果每次合并都恰好把长链接到短链下面，树会变成一条直线：

```
merge(1,2) → 1←2
merge(2,3) → 1←2←3
merge(3,4) → 1←2←3←4
...
```

这时 `find(n)` 要走 `n` 步，单次 **O(n)**。

- `m` 次操作、`n` 个元素：最坏 **O(nm)**。
- 这就是需要优化的原因。

---

## 优化：路径压缩

路径压缩（Path Compression）的核心目标是：**把"往上爬过的路"压平，让下次少走。**

### 代码

```cpp
int find_root(int x) {
    if (fa[x] == x) return x;          // 自己是根，直接返回
    return fa[x] = find_root(fa[x]);   // 先递归找到根，再把自己的父指针改成根
}
```

### 逐行拆解

```
find_root(x)
  ├─ fa[x] == x ?  → 是根，返回 x
  └─ 否则：
       t = find_root(fa[x])   // 递归找到真正的根
       fa[x] = t              // 把 x 的父指针直接改成根（这就是"压缩"）
       return t
```

`return fa[x] = find_root(fa[x]);` 这一行做了三件事：

1. `find_root(fa[x])` 递归求出根 `t`；
2. `fa[x] = t` 把 x 直接挂到根下面；
3. 赋值表达式的值就是 `t`，所以顺便 `return t`。

### 压缩是怎么发生的

递归是"先往下走、再往回弹"的。往回弹的时候，**路径上的每一个结点都执行一次 `fa[u] = 根`**，于是整条路径被拍平：

```
压缩前：                压缩后：
    1                       1
    |                    /  |  \
    2                   2   3   4
    |
    3
    |
    4
```

`find_root(4)` 之后，4、3、2 全都直接指向 1。下次再查它们，**一步到位**。

路径压缩只改**这次查找经过的那条路径**上的点，不会去动别的分支。

### 复杂度：均摊 O(log n)

- 单次最坏仍然是 O(n)——第一次查一条长链时躲不掉。
- 但**均摊**是 **O(log n)**。因为每次走的冤枉路都被"压平"存起来了，后面的查找会越来越便宜。
- 这属于**均摊复杂度**：不是每一次都快，而是把总代价摊到所有操作上以后，平均每次是 O(log n)。
- 空间：O(n)。

> 这里是"均摊"而不是"最坏"，所以不能写成"find 是 O(log n) 最坏"。

## 完整模板

```cpp
#include <iostream>
using namespace std;

const int N = 100010;

int fa[N];

void init(int n) {
    for (int i = 1; i <= n; i++) {
        fa[i] = i;
    }
}

// 递归版：代码短，日常首选
int find_root(int x) {
    if (fa[x] == x) return x;
    return fa[x] = find_root(fa[x]);
}

// 迭代版：n 很大（比如 1e6 以上）时更安全，不会爆栈
int find_root_iter(int x) {
    int r = x;
    while (fa[r] != r) r = fa[r];   // 第一遍：找到根

    while (x != r) {                 // 第二遍：路径上每个点直接连到根
        int nxt = fa[x];
        fa[x] = r;
        x = nxt;
    }
    return r;
}

void merge(int x, int y) {
    int rx = find_root(x);
    int ry = find_root(y);
    if (rx == ry) return;
    fa[rx] = ry;
}

int main() {
    int n, m;
    cin >> n >> m;
    init(n);

    while (m--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) {
            merge(x, y);
        } else {
            cout << (find_root(x) == find_root(y) ? "Y" : "N") << '\n';
        }
    }
    return 0;
}
```

> 洛谷 **P3367【模板】并查集** 就是上面的输入格式，可以用来验证模板。

## 复杂度总表


| 写法 | 单次 find | m 次操作 | 树高 |
| ---- | ----------- | ---------- | ----------- |
| 朴素 | O(n) 最坏 | O(nm) | 可能退化成链，O(n) |
| 路径压缩 | O(log n) 均摊 | O(m log n) | 被压平后很小 |


空间复杂度都是 **O(n)**。

> 注：还有"按秩 / 按大小合并"的写法，可以和路径压缩叠加，理论上进一步降到 O(α(n))。本笔记只讲路径压缩这一条主线。

---

## 易错点

1. **忘记初始化**：`fa[i] = i` 是并查集的命根子。
2. **merge 必须比较根，不能直接改原结点**：`fa[x] = y` 是错的，必须先 `find`。
3. **判断连通要比较 `find(x)` 和 `find(y)`**，不能直接比 `x` 和 `y`。
4. **递归可能爆栈**：极端长链（例如 `n = 10⁶` 时先造一条链再查）会递归 `n` 层，改用迭代版。
5. **路径压缩不能让并查集支持删除或分裂**：它只能合并，不能拆。
6. **多组数据要重新 `init`**：上一组的 `fa` 不清空，下一组直接错。

```
初始：fa = [1,2,3,4,5]

merge(1,2) → fa[2] = 1
merge(3,4) → fa[4] = 3
merge(2,3) → find(2)=1, find(3)=3 → fa[3] = 1

现在树：
        1
       / \
      2   3
          |
          4

find_root(4)：
  4 → 3 → 1
  回弹时 fa[4] = 1，fa[3] = 1

结果：2、3、4 全部直接指向 1，下次一步到根。
```

## 进阶：带权并查集（了解即可）

普通并查集只记"谁是爹"。带权并查集在边上再存一个**权值**，表示"我和我爹的关系"，比如：

- 距离 / 偏移量（到根的差值）
- 敌对关系（0 = 同类，1 = 异类）

查找时要把一路的权值**累加**起来，合并时要**算出补偿量**，比普通并查集多一个 `d[]` 数组和一点推导。

经典题：

- 洛谷 **P2024 [NOI2001] 食物链**（三类关系，模 3）
- 洛谷 **P1525 [NOIP2010] 关押罪犯**（敌人合并，也可二分图）

> 先把普通并查集写熟，再碰带权。

## 一句话总结

**并查集 = 每个集合一棵树 + 只改父指针的合并。**
**路径压缩把查找走过的路拍平，让均摊复杂度从 O(n) 降到 O(log n)。**
