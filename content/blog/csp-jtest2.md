## 四、逐错题详细批注

### 【第1题】文件型病毒传染的主要对象是（）。

- **你的答案**：B（❌）｜ **正确答案**：C
- **错误点**：把"可执行文件"理解窄了：EXE 和 COM 只是 Windows 下的可执行文件后缀，病毒传染的是所有可执行文件。
- **错因归类**：知识缺失
- **猜题策略**：选最一般的选项：看到 EXE/COM 这种"具体后缀"和"可执行文件"这种"类别"并列，先想哪个是上位概念——病毒传染对象是可执行文件这一类，D 只是其中两种后缀。
- **补充知识点**：计算机基础 · 病毒与安全：文件型病毒感染可执行文件（.exe/.com/.elf 等），通过运行带毒文件传播。
- **一句话建议**：记住"病毒传染可执行文件，EXE/COM 只是后缀"。

### 【第3题】内存地址最重要的特点是（）。

- **你的答案**：D（❌）｜ **正确答案**：B
- **错误点**：选了顺序性/连续性——分页、分块机制会打破顺序与连续，但每个地址仍然唯一。
- **错因归类**：知识缺失
- **猜题策略**：抓本质："地址"就是定位编号，定位必须一一对应 → 唯一性。选项里"随机/顺序/连续"都不是必须的。
- **补充知识点**：计算机基础 · 存储：内存地址是每个基本单位的唯一序号；分页/分块可破坏顺序性与连续性。
- **一句话建议**："地址"=唯一编号，想到地图门牌号。

### 【第4题】多媒体计算机是指（）。

- **你的答案**：C（❌）｜ **正确答案**：D
- **错误点**：被"多媒体"字面误导选了"借助多种媒体操作"或"多种功能"——多媒体的"多"修饰的是媒体类型，不是功能数量。
- **错因归类**：知识缺失
- **猜题策略**：定义题直接对应：多媒体 = 多种媒体（文字/声音/图像/视频）→ 能处理多种媒体的计算机。A/B/D 都偏离"媒体"这个核心词。
- **补充知识点**：计算机基础 · 多媒体：同时接收、处理、存储、展示多种类型信息媒体的计算机。
- **一句话建议**：看到"多媒体"就想"处理多种媒体"，别想成"多功能"。

### 【第9题】用浮点表示的数通常由（）组成。

- **你的答案**：A（❌）｜ **正确答案**：C
- **错误点**：把科学计数法的"指数/基数"与浮点数的"阶码/尾数"记混。
- **错因归类**：知识缺失
- **猜题策略**：类比科学计数法：a×10^n 中 a 是尾数（有效数字），n 是阶码（指数）。看到"浮点"直接选"阶码与尾数"。
- **补充知识点**：计算机基础 · 数据表示：浮点数 = 尾数（小数部分）+ 阶码（10 的幂次），类似科学记数法。
- **一句话建议**：浮点=科学计数法：尾数+阶码。

### 【第14题】下列关于数据结构的叙述中，正确的是（）。

- **你的答案**：B（❌）｜ **正确答案**：D
- **错误点**：误以为"二叉排序树最大检索长度为 log₂n"正确——那只是平均检索长度。
- **错因归类**：知识缺失
- **猜题策略**：逐项抓错：A 顺序存储插入删除效率低（错）；B 链表最后一个节点指针域为空（错）；C 是平均检索长度 log₂n 不是最大（错）→ 剩 D。
- **补充知识点**：数据结构 · 树：多叉树转二叉树用"左儿子右兄弟"法，根没有兄弟 → 根无右子树。
- **一句话建议**：树转二叉树：左儿子右兄弟，根无右子树。

### 【第22题】阅读(2) 判断题：程序输出的是 5^n 的值？

- **你的答案**：错（❌）｜ **正确答案**：对
- **错误点**：只看到 num 每次乘 5，忽略输出格式 "0." + 前导 0 + 数字，实际是 0.5^n。
- **错因归类**：程序理解偏差
- **猜题策略**：看输出语句：printf("0") + 补 0 + 输出 num → 输出 [0.xxx](http://0.xxx)（n 位小数）。num = 5^n，整体 = 5^n/10^n = 0.5^n。
- **补充知识点**：程序模拟：大数乘法模拟 num*5 共 n 次 → num=5^n；输出格式决定是 0.5^n。
- **一句话建议**：读程序先看输入输出格式，再追算法。

### 【第23题】阅读(2) 判断题：程序执行到倒数第 3 行时，i 的值为 1？

- **你的答案**：错（❌）｜ **正确答案**：对
- **错误点**：按"循环结束后 i 还有值"的旧式思维判断。
- **错因归类**：程序理解偏差
- **猜题策略**：官方按 C++ 作用域规则判对：每个 for 循环内声明的 i 只在各自循环内有效，循环外不存在可引用的 i（本题以官方答案为准）。
- **补充知识点**：C++ 语法：for 循环内声明的循环变量是块作用域，循环结束后不可见。
- **一句话建议**：C++ 里 for(int i=..) 的 i 出循环即失效。

### 【第24题】阅读(2) 判断题：程序结束前，对任意 1≤i≤a1 都有 0≤num[i]≤9？

- **你的答案**：对（❌）｜ **正确答案**：错
- **错误点**：把"最终状态"误当"全程状态"：num[j] 在乘 5 加进位后、取模前可能超过 9。
- **错因归类**：程序理解偏差
- **猜题策略**：看"程序结束前"的措辞：只要运行过程中存在 num[j]≥10 的时刻即为错。逐语句跟踪：num[j]=num[j]*5+x 这一步可能 ≥10。
- **补充知识点**：程序细节：num[j]*5+x ≥10 时先记录进位 x=num[j]/10，再 num[j]%=10 恢复个位。
- **一句话建议**：判断题盯"程序结束前/任意时刻"这类全程量词。

### 【第28题】阅读(3) 判断题：把 while 前的 fl=0 改为 fl=1，输出必定不变？

- **你的答案**：错（❌）｜ **正确答案**：对
- **错误点**：没分析 ans 初始值 0 与 check(1) 恒真的关系，以为改边界会改答案。
- **错因归类**：程序理解偏差
- **猜题策略**：边界分析：①ans 初值 0，就算二分一次都不进答案也不小于 0；②输入保证 a[i]>0 递增，check(1) 一定成立（相邻差至少…）→ 答案 ≥1，改 fl=1 不影响。
- **补充知识点**：二分答案：答案下界为 1（所有相邻差都 ≥1 或可删到满足），fl 从 0 或 1 开始不影响最终 ans。
- **一句话建议**：判断题改边界：先确认 ans 初值与 check(下界) 恒真性。

### 【第32题】阅读(3) 选择题：输入 25 5 2 / 2 11 14 17 21，输出为（）。

- **你的答案**：A（❌）｜ **正确答案**：B
- **错误点**：手跑二分或枚举删数组合时漏算最优解。
- **错因归类**：程序理解偏差
- **猜题策略**：逆向枚举最优保留集：目标是让相邻差最小最大。试删 2 和 14 → 剩 0,11,17,21,25 → 差 11,6,4,4 → min=4，为最大值。
- **补充知识点**：贪心/二分验证：删数使相邻差最小最大，等价于找能通过的最长"跳石头"距离。
- **一句话建议**：32 题这类模拟题，枚举删哪两个数逐一算最小差。

### 【第39题】完善(2) 完全背包②空：for (int i=1; i<=②; i++) 应填（）。

- **你的答案**：B（❌）｜ **正确答案**：A
- **错误点**：被 w/v 数组有 6 个元素误导，选了 6。
- **错因归类**：程序理解偏差
- **猜题策略**：数物品：题目明确"另有 5 种物品"（重量 5,4,3,2,1）→ i 枚举物品种类 i<=5。w[0]=0 只是占位。
- **补充知识点**：动态规划 · 完全背包：外层 i 枚举物品种类（1..n 种），内层 j 枚举容量。
- **一句话建议**：看题面数物品数，别被数组长度骗。
